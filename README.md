# Space Mining Tycoon V4

V4 conserve automatiquement les sauvegardes V3/V2 et les migre vers `space-mining-v4`.

## Mise à jour
Remplace les fichiers de la racine du dépôt par ceux de cette archive.
Ne supprime pas les données du navigateur.

URL GitHub Pages :
https://nababallah-debug.github.io/Space-mining-tycoon/

## Important
Le classement V4 est actuellement local à l'appareil. Pour un classement mondial et des comptes réellement synchronisés entre appareils, il faut connecter un backend (par exemple Supabase/Firebase) et ajouter une authentification.

## Fonctionnalités V4
- 7 planètes avec bâtiments uniques
- 35 bâtiments
- coûts exponentiels
- prestige uniquement après avoir terminé les 7 planètes
- bonus de prestige appliqué à la production
- clic amélioré et gain par clic affiché
- recherches et technologies
- combo de minage
- boost
- contrats
- missions
- profil/pseudo
- classement local
- sauvegarde/migration V3 -> V4
- gains hors-ligne
- PWA iPhone
